Sources are vendored under `third_party/vendor/` (with only build-needed files
kept). Each upstream `LICENSE` file is kept there verbatim; CMake also copies them
into `build/licenses/`. Keep these notices when redistributing.

`src/importer/xls_locale.c` is this project's Windows UTF-8 bridge for libxls's
locale interface; it avoids relying on the machine's active code page.

The manifest and version resource are emitted by `scripts/makeres.py`, which
writes a COFF resource object directly (no resource compiler needed). The
application icon is drawn by `scripts/make_icon.py` with Pillow; neither script
contributes code to the executable.

Original ClassRollCall 1.5 source remains in `src/ClassRollCall.py` and `tools/`
as an unbuilt historical reference. Copyright (c) 2026 enderLuoxh, MIT License.
The C++ target neither loads nor launches the Python source.

Test fixtures are generated by `scripts/make_fixtures.py` with openpyxl 3.1.5
(MIT), python-docx 1.2.0 (MIT) and xlwt 1.3.0 (BSD). These are development-only
tools and are not linked or bundled.
