# 2.0.1 本机功能修复与验证

日期：2026-11-25。正式 EXE 为 x86 原生 Windows GUI 程序。

## 已修复

- 子菜单移动路径：鼠标斜向移入子菜单时，保留子菜单，等待指针停留后才切换父菜单行。左右展开均覆盖。
- 点名结果显示期间切换模式或班级：先结束当前结果展示，再执行选择，不再静默忽略。
- 触屏菜单：48 DIP 点击行；点按父项展开，点按子项确认；处理 Windows Pointer 与旧 Touch 消息，过滤触摸提升的重复鼠标事件。
- 指针兼容声明：修正 POINTER_INFO 的 InputData 类型、取消标记常量，并避免与新版 SDK 的声明冲突。
- 菜单选中标记：居中的 14 DIP 正方形绘制区，保持对勾比例。
- 开机启动开关：不再沿整行文字绘制虚线框；键盘焦点使用开关周围的紧凑提示，并遵循系统隐藏焦点状态。
- 程序资源：合并同类型图标资源，按资源类型 ID 排序，Windows 可正常读取图标、清单和版本。
- 界面中点分隔符全部改为空格或逗号，姓名数据保持原样。
- 增加“考生姓名”表头识别。
- 菜单会话使用自动清理，关闭菜单或发生异常时释放窗口、计时器与捕获；防止菜单重入。
- 检测到旧后台实例但找不到悬浮按钮时显示提示，不再无提示退出；正常重复启动重新显示并约束按钮位置。
- 专用版支持：独立数据目录、单实例锁、窗口类与启动项；本地生成内置名单，不把姓名放进公开源码。

之前修复的名单被占用时位置保存、设置文件写入失败时正常退出、菜单打开时传递退出消息等行为保留。

## 已在本机验证

测试使用独立配置和虚构名单，不修改真实开机启动项。

- 核心测试：均衡抽取整轮无重复、随机分布、DPI 换算、负坐标显示器、重名保留、名单占用时独立保存位置。
- 导入测试：17 个独立生成的编码、CSV、XLS、XLSX、DOCX 正常/异常样本；补充考生姓名表头测试。
- 功能界面：拖动、点名显示和自动收起、父子菜单返回与直接点击、编辑重名名单、拖入多工作表 Excel 并确认预览、单实例、锁定设置文件且菜单打开时退出、重启恢复位置、首次启动不默认开机自启。
- 实际桌面鼠标：左右展开子菜单的连续移动路径、模式与班级切换，以及结果显示期间切换。
- Windows 触摸注入：短按点名、长按菜单、点按模式/班级、拖动并保存位置、结果自动收起。
- 连续 35 次打开/关闭子菜单，GDI 与 USER 资源计数均保持 15 / 6。
- Windows 自身的资源查找、Shell 图标提取与版本信息读取；九种图标尺寸；原生 PE32，无 CLR/.NET 目录。
- 专用版：与本地输入逐条比对，首次无需导入，两个版本同时运行，设置互不覆盖，抽取属于对应名单，退出与重启保留数据。
- 视觉检查：当前系统 150% 缩放下的菜单对勾与开机启动开关。

## 运行依赖和未验证范围

当前 Zig 产物依赖 Windows 10/11 自带 UCRT 与系统 DLL，不依赖 .NET、Python、Qt、VCRUNTIME 或 MSVCP DLL。
Windows 7/8、实体教室触摸屏、混合 DPI 多显示器、实际 PPT 放映仍需目标设备验收。
Windows 触摸注入用于检查真实消息路径，不能替代实体触屏测试；不承诺绝无崩溃。
本轮本机使用 Zig 编译；MSVC/CMake 路径由仓库 CI 另行检查。

参考：[Microsoft POINTER_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-pointer_info)、
[Microsoft 触摸注入示例](https://github.com/microsoft/Windows-classic-samples/blob/main/Samples/InjectTouchPointerInput/cpp/InjectTouch.cpp)。
