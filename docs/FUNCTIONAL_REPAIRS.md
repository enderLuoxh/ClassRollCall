# DSH 界面版功能修复 · 2026-11-25

保留 DSH 已完成的按钮、结果卡片、圆角菜单与设置页外观；本轮没有修改绘制代码或布局尺寸。

## 修复

- 拖动结束只保存设置，不再重新读取每份名单、重写班级索引。名单被其他程序占用时，位置保存仍能成功。切换班级、抽取模式和开机启动选项也使用独立的设置保存。
- 子菜单捕获鼠标后，直接点击主菜单其他项能够正确执行；从子菜单移回主菜单时，不再因捕获转移而意外关闭整个菜单。
- 菜单打开时退出会保留并向外层传递退出消息，避免窗口消失但进程仍在。
- 退出或系统关闭时，即使设置文件无法写入，也会继续释放托盘图标、计时器和结果窗口，并结束进程。
- 托盘注册失败后最多尝试五次，成功或达到上限后停止重试；收到资源管理器重启消息后重新注册。托盘不可用时保留悬浮按钮，避免隐藏后失去入口。
- 开机启动注册失败时，将设置页复选框还原为实际状态。
- 补齐 CMake 缺少的菜单、皮肤和预览源文件；补上 RC 版本的同款应用图标。
- 更新旧界面冒烟测试中的按钮尺寸，移除已删除的“关于”页检查。

## 已验证

使用隔离目录和虚构名单，没有修改用户的实际名单或开机启动注册表。

- 核心测试：随机/均衡抽取、DPI 坐标、重复姓名存取、名单独占锁下独立保存设置。
- 导入测试：17 份独立生成的 TXT、CSV、XLS、XLSX、DOCX 正常/异常样本。
- `tests/functional_ui.py`：名单独占锁下拖动；点名结果显示和自动消失；子菜单直接点击主菜单、移回主菜单；编辑班级并保留同名记录；拖入多工作表 XLSX、自动选择姓名工作表、预览去重、确认保存；单实例；菜单打开且设置文件独占锁定时退出；重启恢复位置；首次启动默认不勾选开机启动。
- EXE 检查：x86 Windows GUI 子系统、清单、版本信息、九种尺寸的应用图标资源。

本轮已验证的程序位于 `dist/ClassRollCall-repaired.exe`。标准编译入口仍为 `scripts/build_zig.py`；本次受执行环境的 Zig 缓存文件访问限制，使用同一 Zig 包内的 Clang/LLD 和既有 x86 运行库缓存完成构建。

## 仍需实际设备确认

当前执行会话没有 Explorer 系统托盘，因此未声称已验证真实托盘显示或资源管理器重启后的图标恢复。Win7、实体触摸屏和跨显示器不同缩放比例也未在本轮实机验证。当前 Zig 产物依赖 UCRT，不能据此承诺未安装运行库更新的 Win7 可直接运行。
