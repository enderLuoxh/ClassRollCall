# 测试记录

本文件只记录**实际运行过**的检查及其结果，并单列必须在真实设备上完成的验收项。
编译通过、API 存在、代码里有降级分支，都不算通过。

## 构建环境

- 测试机：Windows 11 10.0.26300，单显示器 2560 × 1600 @ 150%（192 DPI 缩放、144 DPI 实测），
  该会话没有 explorer.exe 外壳（因此托盘无法验证）。
- 本机无 Visual Studio / Windows SDK，本轮构建使用 zig 0.13.0 交叉编译
  （`zig c++ --target=x86-windows-gnu`，Release `-O2 -DNDEBUG`）。
- 两个 C++ 测试程序同样由 zig 构建、在本机原生运行。

## 自动化测试内容

### core_tests（`tests/core_tests.cpp`）

- 均衡抽取：固定种子，37 人 × 100 轮，每轮索引不重复。
- 单人名单正常抽取；空名单抛 `std::invalid_argument`。
- 完全随机：5 人 × 50000 次，每人次数落在 9000–11000。
- DPI 换算：96 / 120 / 144 / 168 / 192 下 `px()` 结果正确；负坐标显示器边界夹取。
- 持久化：临时目录写入 / 读取，中文班名、重复姓名、按钮位置往返一致，结束后清理。

补充手工驱动验证：

- 拖放导入：Python 构造 `HDROP` 投递 `WM_DROPFILES`，单个与 5 个文件同时拖入均正确生成班级。
- 剪贴板导入：管理窗口 → 导入名单 → 从剪贴板粘贴 → 预览「3 位学生」，确认后
  `rosters/` 新增文件，内容为剪贴板三行姓名，班级名默认「粘贴的班级」。
- 多工作表导入：自动选中「名单」表（而不是第一张「说明」表），只导入姓名列。
- 深色主题：`settings.ini` 的 `theme=dark` 生效，卡片变深、文字变浅。

抓图与截图说明：本轮所有截图均由 `PrintWindow` 获取（分层窗口无法用屏幕拷贝截取），
窗口边框区域可能呈黑色，属截取伪影。
