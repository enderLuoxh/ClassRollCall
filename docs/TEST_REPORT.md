# 测试记录

本文件明确区分已运行的检查和必须在实际设备完成的验收。不得将 API 模拟或
编译成功当成触摸屏、多屏、旧系统测试通过。

## 构建环境

- 本地工作机：Windows 11，10.0.26300；没有可用 C++ 编译器，Git 直连 DNS 失败。
- 构建由 GitHub Actions Windows Server 2022 x86 MSVC Release 执行。
- `/MT` 静态运行库，所有解析库静态链接。最终依赖必须以发布构建 imports.txt 为准。

## 自动化覆盖

| 检查 | 方法 |
|---|---|
| 均衡抽取 | 固定种子下 100 个 37 人轮次，校验每轮索引唯一 |
| 完全随机 | 50000 次抽取，检查范围及宽容统计阈值 |
| 边界 | 空名单抛错、单人名单、同名不同记录 |
| DPI 算术 | 96/120/144/168/192 DPI 换算和负坐标显示器边界夹取 |
| 持久化 | 实际临时目录写入 / 读取、Unicode 班名和重复姓名、位置恢复 |
| 文本 / CSV | UTF-8/BOM、UTF-16 LE/BE BOM、GBK、GB18030、引号分隔和多行字段 |
| XLS | xlwt 写出的中文、多列、多工作表真实 BIFF 文件，由 libxls 读取 |
| XLSX | openpyxl 真实文件、多工作表、内联字符串、共享字符串和缓存公式 |
| DOCX | python-docx 真实段落 / 表格文件 |
| 导入选择 | 自动姓名表头、无表头多列拒绝猜测、手动选列、重复保留 / 去重、空白 |
| 输入安全 | 损坏 ZIP、超大解压项、DOCTYPE / 外部实体、未闭合 CSV 引号 |
| GUI 冒烟 | 实际启动 Release，消息触发三次抽取，验证均衡、置顶、不激活、穿透、关闭、第二实例退出 |
| 性能 | 实际进程空闲两秒 CPU 累计时间、工作集、线程数和 EXE 字节数 |

`scripts/smoke.ps1` 在独立 GUID 临时数据目录运行，不读取或修改真实教师名单及
开机启动设置。模拟鼠标消息的冒烟不代表实体触摸或物理鼠标点击实测。

## 尚需实机验收

- Windows 7 SP1 干净虚拟机：加载、导入六入口、字体、主题降级、托盘和退出；
  无 VC++ / UCRT 安装环境必须实际启动，检查所有间接导入，不能凭 `/MT` 认定通过。

- 混合 DPI 多显示器：拖动换屏、重启恢复、移除显示器、负坐标副屏。
- 鸿合实体触摸：点按、拖动、500 ms 长按、取消、连续点按、模拟鼠标去重。
- PPT 放映状态下抽取、菜单和文件拖入；结果卡片穿透真实输入、不改变放映焦点。
- 系统主题切换和原生设置窗口可读性；屏幕键盘 / 触摸组合框及菜单操作。
- 开机启动开关、路径含空格及中文、EXE 移动修复、普通用户权限、中文 Windows 用户名。
