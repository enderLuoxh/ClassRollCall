# 2026-11-25 界面更新

用户后续反馈：“导入的ui不够现代化，按钮会不会小了一点”“所有的UI都不够现代化”。
本次统一更新整个应用，悬浮按钮尺寸以此更新为准，覆盖初始规格中的尺寸建议。

| 界面 | 当前实现 |
|---|---|
| 悬浮按钮 | 96 × 56 DIP 的蓝色圆角按钮，Call 20 DIP，默认半透明，点击反馈保持 |
| 结果卡片 | 统一圆角、配色、字体和强调色，仍然不激活且穿透输入 |
| 快捷菜单 | 48 DIP 高触摸行，圆角选中背景，统一配色与留白 |
| 首次设置 | 标题、名单导入卡片、自启动开关和底部主操作 |
| 班级管理 | 卡片名单列表、人数辅助信息、顶部导入工具和底部编辑操作 |
| 名单编辑 | 大标题、独立班名输入框、逐行名单编辑区、统一保存 / 取消 |
| 导入预览 | 左侧表单、右侧名单预览，去重开关、统计和底部确认操作 |
| 文件选择 | 系统 IFileOpenDialog，多选文件，保留 Windows 7 API 兼容路径 |
| 提示窗口 | 关于、删除确认、重名选择、空名单、启动路径修复与错误共用主题窗口 |

主操作按钮高 48 DIP；开关区域高 48 DIP；列表行高 48 DIP。保留原生键盘、焦点、
列表与组合框行为，通过轻量绘制统一外观。不使用浏览器、UI 框架、实时模糊或常驻动画。
窗口只在交互、主题变化与 DPI 改变时重绘；悬浮按钮空闲没有刷新定时器。

新增界面冒烟：真实打开班级管理、保存新班级、文件拖入、工作表切换、重复保留 / 去重、
确认导入并检查落盘名单、关于窗口和首次设置。检查按钮实际像素尺寸与 DPI 的换算。
CI 的内部截图只用于核对实际界面，不包含真实教师或学生数据。

Win7 干净系统、鸿合实体触摸、混合 DPI 多屏、真实 PPT 焦点行为依然需要实机验收。
