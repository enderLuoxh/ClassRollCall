# 界面说明（最终版）

本文件记录 ClassRollCall 2.0 最终采用的外观与尺寸，避免后续改动偏离。

## 设计约束

教师使用，稳定优先：不使用渐变、图片、实时模糊、阴影或任何持续动画。
所有尺寸以 DIP 计算，实际像素 = DIP × DPI / 96。浅色 / 深色配色为中性灰白 + Windows 蓝。

## 悬浮按钮

- 白色圆角矩形，圆角 = 高度的 19%，**无图标、无阴影、无边框装饰以外的元素**。
- 卡片 112 × 64 DIP，窗口 124 × 76 DIP（四周各 6 DIP 透明边，用于 DPI 与摆位）。
- 文案「点名」，粗体，字号 = 卡片高度的 30%，垂直水平居中，颜色为正文色。
- 平时整体不透明度 128/255（约 50%）；按下与抽取期间 242/255（约 95%），结束后恢复。
- Hover 极轻微加深（浅色混 3% 黑 / 深色混 6% 白），按下再深一点；不使用放大或位移。
- 抽取期间中心显示细圆环进度（1 秒走完一圈），结束后回到静态文字。

## 结果卡片

- 460 × 168 DIP 白色（深色主题为深灰）圆角卡片，圆角 = 高度的 10.5%，1 像素描边。
- 只显示姓名：粗体，字号为高度的 34%，超长自动缩小，最小 12%。
- 不显示班级名、进度、序号；无阴影。居中于悬浮按钮所在显示器的可用区域。
- 时间线：0–1000 ms 快速滚动姓名，1000–4000 ms 定格结果，4000–4240 ms 淡出并隐藏。
- 窗口带 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，不接收输入、不抢焦点。

## 右键菜单

- 自绘圆角弹层（半径 10 DIP），白色卡片 + 1 像素描边，无阴影。
- 行高 38 DIP，左右内边距 14 DIP，选中行用浅灰圆角背景，左侧勾选标记，子菜单右侧 chevron。
- 由 `SetCapture` 接管鼠标：点击卡片外、Esc、选择条目都会关闭；不依赖窗口激活，
  因此 `WS_EX_NOACTIVATE` 的悬浮窗也能可靠弹出和关闭。
- 支持触摸（长按 500 ms 打开）与键盘方向键 / 回车。

## 管理窗口

Windows 11 设置式布局：左侧导航（班级名单 / 导入名单 / 使用偏好），右侧内容卡片，
底部主操作按钮。导入预览为独立对话框，包含工作表 / 姓名列 / 表头行数选择与姓名样例。
不提供「关于」页，也不显示任何「完全离线」之类的宣传文案。
